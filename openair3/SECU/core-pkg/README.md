This module implements the Core Private Key Generator (PKG) for the TESLA Identity-Based Signature (IBS) scheme used in 5G NR SIB1 authentication.

## Overview

In the IBS scheme, the Core PKG:
1. Generates and securely stores the master secret key (Ed25519 seed)
2. Publishes the master public key (MPK, derived via `crypto_sign_seed_keypair`)
3. Issues gNB-specific secret keys by signing the identity message with `crypto_sign_detached`

UEs only need the master public key (MPK) pre-provisioned (e.g., in SIM) to verify signatures from any gNB whose key was issued by this PKG.

## Dependencies

- `openssl` (with Ed25519 support)
- `python3`

## Usage

```bash
# 1. Generate master keypair
./tf5_ibs_keygen.sh pkg_keys/msk.bin pkg_keys/mpk.bin

# 2. Issue gNB secret key (Cell ID = 9 hex chars, validity = minutes since 2024-01-01)
./tf5_ibs_issue.sh pkg_keys/msk.bin 123456789 1051200 gnb_keys/sk_gnb1.bin
```

**Output:**
- `msk.bin` (32 bytes) - Master secret key (Ed25519 seed). **KEEP SECURE!**
- `mpk.bin` (32 bytes) - Master public key. Distribute to all UEs.
- `sk_gnb1.bin` (67 bytes) - gNB's secret key (y[32] + pk[32] + validity[3]). Transfer securely to gNB.

### Deploy Keys

**gNB Configuration:**
```bash
./nr-softmodem -O gnb.conf --tf5-privkey /path/to/sk_gnb1.bin
```

**UE Configuration:**
```bash
./nr-uesoftmodem -O ue.conf --tf5-core-mpk /path/to/mpk.bin
```

## File Formats

| File | Size | Format | Permissions |
|------|------|--------|-------------|
| Master Secret (msk) | 32 bytes | Ed25519 seed (raw) | 0600 (owner only) |
| Master Public (mpk) | 32 bytes | Ed25519 point, compressed | 0644 (public) |
| gNB Secret (sk_id) | 67 bytes | y[32] scalar + pk[32] point + validity[3] BE | 0600 (owner only) |

## Security Considerations

### Master Secret Protection

The master secret key (`msk.bin`) is the root of trust:
- If compromised, attacker can forge keys for any Cell ID
- Store in HSM or encrypted storage in production
- Limit access to authorized personnel only
- Consider threshold cryptography for high-security deployments

### Key Distribution

- **MPK to UEs**: Can be distributed openly (public key)
- **sk_ID to gNB**: Must be transferred over secure channel
  - Use encrypted transport (TLS, SSH)
  - Verify gNB identity before issuing key
  - Audit all key issuance operations

### Cell ID Binding

The gNB's Cell ID is cryptographically bound to its secret key:
- Changing Cell ID requires reissuing the key
- UE derives verification key from Cell ID in received SIB1
- Mismatch causes verification failure

## IBS Scheme Details

See [doc-tf5/pkg-cryptography.md](../../../doc-tf5/pkg-cryptography.md) for the full cryptographic specification.

**Summary:**
- **Curve:** Ed25519 (via libsodium)
- **Scheme:** GG09 Schnorr IBS (Galindo-Garcia, 2009)
- **Identity hash:** `cid = SHA-512(pk ‖ mpk ‖ cell_id ‖ validity) mod l`
- **Extract:** `(R‖S) = Ed25519_sign(msk, id_msg)`, `sk_id = (y=S, pk=R)` (deterministic)
- **Sign:** `r ← Z_l, R = r·B, h = H(data‖R), σ = h·y + r`
- **Verify:** `cid = SHA-512(pk ‖ mpk ‖ id_msg) mod l, Q = cid·MPK + pk, R' = σ·B − h·Q, check R' == R`

## Integration with OAI-TF5

The gNB and UE in `oai-tf5/` use keys generated by this PKG:

1. gNB loads `sk_ID` via `--tf5-privkey` and signs SIB1 messages
2. UE loads `MPK` via `--tf5-core-mpk` and verifies signatures
3. UE extracts Cell ID from SIB1's `cellIdentity` field
4. Verification uses `R' = σ·B − h·Q` where `Q = cid·MPK + pk`
