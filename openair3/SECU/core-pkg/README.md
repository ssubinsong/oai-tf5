# TF5 Core PKG - Identity-Based Signature Private Key Generator

This module implements the Core Private Key Generator (PKG) for the TESLA Identity-Based Signature (IBS) scheme used in 5G NR SIB1 authentication.

## Overview

In the IBS scheme, the Core PKG:
1. Generates and securely stores the master secret key (`s`)
2. Publishes the master public key (`MPK = s*Q`)
3. Issues gNB-specific secret keys based on their NR Cell ID

UEs only need the master public key (MPK) pre-provisioned (e.g., in SIM) to verify signatures from any gNB whose key was issued by this PKG.

## Dependencies

This module depends on [libsodium](https://doc.libsodium.org/) for Ed25519 elliptic curve operations. libsodium is built via `ExternalProject_Add` in the root `CMakeLists.txt`.

## Building

### Building with OAI (Recommended)

The PKG utilities are built automatically when building OAI with TESLA enabled:

```bash
cd cmake_targets
./build_oai --ninja --gNB --nrUE --cmake-opt -DENABLE_TF5=ON
```

Or using CMake presets:
```bash
cmake --preset default
cmake --build --preset 5gdefault
```

This produces two utilities in `cmake_targets/ran_build/build/`:
- `tf5_ibs_pkg_keygen` - Master keypair generation
- `tf5_ibs_issue` - gNB secret key issuance

## Usage

### 1. Generate Master Keypair (One-time Setup)

```bash
./tf5_ibs_pkg_keygen pkg_keys/msk.bin pkg_keys/mpk.bin
```

**Output:**
- `msk.bin` (32 bytes) - Master secret key. **KEEP SECURE!**
- `mpk.bin` (32 bytes) - Master public key. Distribute to all UEs.

### 2. Issue gNB Secret Key

For each gNB, issue a secret key based on its NR Cell ID:

```bash
# Cell ID is 36 bits, provided as 9 hex characters
./tf5_ibs_issue pkg_keys/msk.bin 123456789 gnb_keys/sk_gnb1.bin
```

**Output:**
- `sk_gnb1.bin` (64 bytes) - gNB's secret key (y[32] + pk[32]). Transfer securely to gNB.

### 3. Deploy Keys

**gNB Configuration:**
```bash
./nr-softmodem -O gnb.conf --tf5-privkey /path/to/sk_gnb1.bin
```

**UE Configuration:**
```bash
./nr-uesoftmodem -O ue.conf --tesla-mpk /path/to/mpk.bin
```

## File Formats

| File | Size | Format | Permissions |
|------|------|--------|-------------|
| Master Secret (msk) | 32 bytes | Ed25519 scalar, little-endian | 0600 (owner only) |
| Master Public (mpk) | 32 bytes | Ed25519 point, compressed | 0644 (public) |
| gNB Secret (sk_id) | 64 bytes | y[32] scalar + pk[32] point | 0600 (owner only) |

## Security Considerations

### Master Secret Protection

The master secret key (`msk.bin`) is the root of trust:
- If compromised, attacker can forge keys for any Cell ID
- Store in HSM or encrypted storage in production
- Limit access to authorized personnel only
- Consider threshold cryptography for high-security deployments

### Key Distribution

- **MPK to UEs**: Can be distributed openly (public key)
- **sk_ID to gNB**: Must be transferred over secure channel
  - Use encrypted transport (TLS, SSH)
  - Verify gNB identity before issuing key
  - Audit all key issuance operations

### Cell ID Binding

The gNB's Cell ID is cryptographically bound to its secret key:
- Changing Cell ID requires reissuing the key
- UE derives verification key from Cell ID in received SIB1
- Mismatch causes verification failure

## IBS Scheme Details

See [doc-tf5/pkg-cryptography.md](../../../doc-tf5/pkg-cryptography.md) for the full cryptographic specification.

**Summary:**
- **Curve:** Ed25519 (via libsodium)
- **Scheme:** GG09 Schnorr IBS (Galindo-Garcia, 2009)
- **Identity:** NR Cell ID (36 bits) || validity_end (24 bits)
- **Extract:** `b ← Z_l, pk = b·B, cid = H(id‖pk‖mpk), y = cid·z + b`
- **Sign:** `r ← Z_l, R = r·B, h = H(data‖R), σ = h·y + r`
- **Verify:** `cid = H(id‖pk‖mpk), Q = cid·MPK + pk, R' = σ·B − h·Q, check R' == R`

## Integration with OAI-TF5

The gNB and UE in `oai-tf5/` use keys generated by this PKG:

1. gNB loads `sk_ID` via `--tf5-privkey` and signs SIB1 messages
2. UE loads `MPK` via `--tesla-mpk` and verifies signatures
3. UE extracts Cell ID from SIB1's `cellIdentity` field
4. Verification uses `R' = σ·B − h·Q` where `Q = cid·MPK + pk`
