## Serena MCP — Primary Development Toolchain (Mandatory)

Use Serena as the **primary tool** for ALL code interaction — exploration, navigation, editing, refactoring, and search. Prefer Serena over raw file reads, text-based grep, and line-based edits whenever possible. Fall back to non-Serena tools only for non-code files, intra-symbol line edits, or shell/git operations.

Use **all** of Serena's capabilities fully: onboarding, project memories, symbolic exploration, symbol-level editing, refactoring, thinking/reflection checkpoints, and pattern search. Read Serena's instruction manual (`initial_instructions`) if unsure which tool to use.
